　なんかひとつの物を見て、少し動いてみる。

そうすると、物の見えが動く。

だけど、その時、見えている風景もまるごと動きますよね。

ということは、ひとつの物を見る、と見えの全体を見る、

って、同じことでは？　当たり前かもしれんが。


　一点を見る、と全体を見る、がセットか?

---

　白い水筒が目の前にありまして。まあ、何でもいいんですけど。

水筒のこっち側が見えてます。

しかし、横側の見えもあるはずじゃないですか。

ちょっと、鏡を水筒の左側に置いてみました。

するとやっぱり、水筒の左側が写ってます。

光は左側横方向にもいってるみたいです。

が、その横方向への光は見えませんよね。

見えちゃったら、背景が見えなくなるし、ワケわからんことに

なっちゃいますよー。

　ということは、見えている光は、奥行き軸のみでは?

この奥行き軸が虚軸だとすると、全方向見たら、虚軸の球集合。

自分を中心軸にしちゃって、周りの空間は虚空間では?

　まあ、ご自分で考えてみて～(*´▽｀*)

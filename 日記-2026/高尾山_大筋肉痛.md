２０２６　５月７日


　友人が連休に高尾山いきまして。

股関節の大筋肉痛で戻ってきましてね。

中学以来の大筋肉痛。

ほぼ、負傷(*´ω｀)


膝上がらない。ズボンもって引き上げないと無理。

便所の敷居すら困難。あははー( ＾ω＾ )

　歩き始めて３０分あたりで、

｢この歩き方じゃ駄目だ～｣

となり、後は地獄。

　少数の慣れた人たち以外の都会っこは

ほぼみんな、マジ顔になってたらしいんで、

まあ、全滅でしょうか。( ＾ω＾ )


　なぜか行っちゃうんですね。ギり行けるんですね。

みんな行ってるし、下りてくる人もおるし、、、

ここで引き返したらダサいかー、、、と。

　人の目ってのもいい効果ありかなー。

　

　｢おれは怠けてた。｣

と、清々しく反省してました。


　そんで、おしゃべりしてて、深い話になったりするんよ。

そこで、ふと、

｢そういや、高尾山にやられてるんよねー。｣

｢そう。そうなんだよー。f(^_^)｣

｢あははー。｣

となります。

　皆さんも、ぜひ、自然に優しくボコられて

から、哲学とか研究について今一度思いをめぐらせてみては?

( ＾ω＾ )
